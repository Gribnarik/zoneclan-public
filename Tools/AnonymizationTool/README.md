# ZoneClan Database Anonymization Tool

Этот инструмент анонимизирует Discord ID и имена игроков в базе данных ZoneClan для безопасной публикации.

## Назначение

Подготовка проекта ZoneClan для публикации на GitHub:

- Замена реальных Discord ID на фейковые (диапазон 1100000000000000000-1199999999999999999)
- Замена реальных имен на геймерские ники (например, "ShadowHunter", "IronWolf87")
- Сохранение всей статистики, связей и игровых данных

## Зависимости

- .NET 10.0+ SDK
- MySQL база данных с данными ZoneClan
- Строка подключения к базе данных

## Установка

```bash
cd Tools/AnonymizationTool
dotnet restore
```

## Использование

### Вариант 1: Использование C# инструмента (рекомендуется)

```bash
# Dry run - показать изменения без внесения изменений
dotnet run -- "Server=localhost;Database=clan_hub;User=root;Password=yourpass" --dry-run

# Реальная анонимизация
dotnet run -- "Server=localhost;Database=clan_hub;User=root;Password=yourpass"
```

### Вариант 2: Использование SQL скрипта напрямую

1. Сначала запустите C# инструмент для генерации CSV:
   ```bash
   dotnet run -- "your_connection_string" --dry-run
   ```

2. Это создаст файл `discord_id_mapping.csv`

3. Запустите SQL скрипт в MySQL:
   ```sql
   source anonymize_database.sql
   ```

## Что анонимизируется

### Заменяемые данные:
- **Discord IDs** (все таблицы): Реальные Discord сноуфлейки → Фейковые ID (диапазон 11xxxxxxxxxxxxxxxxxx)
- **Имена игроков**: Реальные ingame имена → Геймерские ники (например, "ShadowHunter", "IronWolf87")
- **Guild ID** в clan_settings: Реальный guild ID → 1000000000000000000
- **Updated_by** поля: Реальные ID пользователей → 0

### Сохраняемые данные:
- Вся статистика K/D/A
- История матчей и даты
- Сборки игроков и статы брони
- Назначения в отряды и роли
- Штрафы и заметки
- Записи посещаемости
- Все внешние ключи

## Безопасность

1. **Dry run режим**: Тест без изменений с флагом `--dry-run`
2. **CSV маппинг**: Генерация CSV файла с отображением old→new ID
3. **Изоляция диапазона**: Новые Discord ID в специальном диапазоне (11xxxxxxxxxxxxxxxxxx) чтобы не конфликтовать с реальными
4. **Сохранение ключей**: Все связи сохраняются после анонимизации
5. **Проверка запросов**: Скрипт включает проверки анонимизации

## Проверка

После запуска инструмента проверьте анонимизацию:

```sql
-- Проверить, все ли Discord ID в анонимизированном диапазоне
SELECT COUNT(*) as players_with_real_ids
FROM players
WHERE discord_id < 1100000000000000000 OR discord_id > 1199999999999999999;

-- Должно вернуть 0
```

## Восстановление исходных данных

Инструмент создает `discord_id_mapping.csv` который можно использовать для обратного преобразования (но база всегда резервируется перед анонимизацией).

## Таблицы базы данных

Инструмент обновляет эти таблицы (и любые другие с player_id внешними ключами):

1. `players` - Основная таблица игроков
2. `match_tab_players` - Статистика игроков для матчей
3. `player_stage_status` - Статус прохождения этапов
4. `player_builds` - Сборки оборудования игроков
5. `player_armor_stats` - Статы брони
6. `player_roles` - Назначения ролей
7. `player_penalties` - Записи штрафов
8. `player_snipers` - Статы снайперок
9. `player_notes` - Админ заметки
10. `squad_members` - Назначения в отряды
11. `attendance` - Записи посещаемости
12. `player_bans` - Записи банов
13. `clan_settings` - Настройки гильдии

## Решение проблем

### Ошибка: "Table doesn't exist"
Убедитесь, что вы подключаетесь к правильной базе данных и таблицы созданы.

### Ошибка: "Access denied"
Проверьте, что у пользователя MySQL есть права UPDATE на все таблицы.

### Ошибка: "No players found"
База данных может быть пустой или в неправильном состоянии. Проверьте:
```bash
mysql -u root -p -e "USE clan_hub; SELECT COUNT(*) FROM players;"
```

### CSV файл не генерируется
Проверьте права записи в текущую директорию.
